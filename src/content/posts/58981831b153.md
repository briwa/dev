We had this assignment back in uni. A presentation in front of the class on a topic of our choosing. We would get "awards" on a few categories, including "best presentation". Being a huge computer nerd at the time, I was like, I got this.

I lost the award to my friend, though; his was made with Adobe _freaking_ Flash. He created a really cool, tree-growing like animation which my fancy PowerPoint transitions could never compete.

That experience, mostly for its concept, stuck with me: fractals. [Wikipedia says](https://en.wikipedia.org/wiki/Fractal) it is a form of recursive algorithm. My young self didn't ask how he did it out of pettiness :p but, here's my own spin on this:

```sandbox=js viz 480x480 code
const { Scene, layer, line, tween, wait, sequence, polar, easeInOutSine, easeInOutSineInverse } = Canvas;

const DISTANCE_RATIO = 0.7;
const BASE_LENGTH = 110;
const BASE_THICKNESS = 8;
const ANGLE_DIFF = 100;
const BRANCH_COUNT = 3;
const MAX_DEPTH = 6;
const GROW = 300;
const FADE = 800;
const HOLD = 1500;
const color = { r: 224, g: 122, b: 95 };

function branch({ start, angle, length, lineWidth }, depth = 0) {
  const end = polar(start, angle, length);
  const shape = line({
    x0: start.x,
    y0: start.y,
    x1: end.x,
    y1: end.y,
    lineWidth,
    ease: easeInOutSine,
    color,
  });

  const grow = sequence(
    wait(FADE + (depth * GROW)),
    tween({ t1: 1 }, { duration: GROW, ease: easeInOutSineInverse }),
  );

  const spread = ANGLE_DIFF / BRANCH_COUNT;
  const center = (BRANCH_COUNT - 1) / 2;
  let children = [];

  if (depth <= MAX_DEPTH) {
    children = Array.from({ length: BRANCH_COUNT }, (_, i) =>
      branch(
        {
          start: end,
          angle: angle + (i - center) * spread,
          length: length * DISTANCE_RATIO,
          lineWidth: Math.max(lineWidth - 1.5, 1),
        },
        depth + 1,
      ),
    );
  }

  return layer([layer([shape], grow), ...children]);
}

const tree = branch({
  start: { x: width / 2 - BASE_THICKNESS / 2, y: height },
  angle: 0,
  length: BASE_LENGTH,
  lineWidth: BASE_THICKNESS,
});

const scene = new Scene({
  canvas,
  layers: [
    layer(
      [tree],
      sequence(
        tween({ alpha: 0 }, { duration: FADE }),
        tween({ t1: 0, alpha: 1 }, { duration: 0 }),
      ),
    ),
  ],
});

scene.onFinish(() => reset());

loop((t) => scene.render(t));
```

A few simple rules, repeated over and over:
- a branch will create a few new branches
- the new branches will grow shorter and thinner than the original branch
- the new branches will grow apart at specified angles
